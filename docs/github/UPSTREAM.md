Attribution and private repository visibility do not by themselves establish redistribution permission.

Original game media, Turbo Pascal binaries, native SDK/library binaries and personal saves are not included. Use your own original installation for native play. Licensing/permission resolution remains a publication prerequisite, not something this port claims to have completed.
